# Mage Home

Клиентский строитель домов для Minecraft Java 1.21.11, Fabric и UnionClef 0.95.61.
Fabric-аддон подготавливает участок, строит по схеме, проверяет результат и сохраняет
прогресс в игровом профиле. Python-пакет проектирует дома по описанию и проверяет
предложения игрового эксперта. Готовые схемы выполняются без вызова модели.

- `src/` и `core/` содержат клиентский исполнитель и проверку игровых операций.
- `python/` содержит проектировщик и игровой эксперт.
- `spec/` определяет форматы управления, чертежа и журнала.
- Saruman Lab использует локальный [адаптер Mage Home](../../adapters/README.md).
  Он передаёт клиенту путь к Python-пакету из этого каталога.

## Установка для игры

Список файлов, ссылка на скачивание и команды проверки есть в
[руководстве Mage Home](../../docs/MAGE_HOME_RU.md#установка).

Установите проверенные клиентские JAR Mage Home 0.1.10 и UnionClef 0.95.61
в `mods` профиля Minecraft 1.21.11 с Fabric Loader 0.19.2 и Fabric API.
Это отдельные файлы поставки. После входа в игровой мир включите Mage Home в Lab.
Для снабжения персонажа можно предоставить право `/give`.

## Сборка из исходников

Понадобятся JDK 21, Gradle 9.2.1, Python 3.10 или новее и тот же JAR UnionClef.
В каталоге `integrations/mage-home` выполните:

```text
python tools/prepare_unionclef.py <путь-к-unionclef-1.21.11-0.95.61.jar>
gradle build
```

Скрипт сверяет SHA-256 и извлекает вложенные зависимости UnionClef в локальный
`libs/`. Gradle получает остальные зависимости из репозиториев, указанных в конфигурации.
В POSIX-среде с установленным Gradle 9.2.1 также можно использовать `./gradlew build`
или `sh ./gradlew build`. Сборка создаёт `build/libs/mage_home-0.1.10.jar`.

Собрать отдельный wheel для использования без Saruman можно командой
`python -m pip wheel --no-deps .` из каталога `python/`.
