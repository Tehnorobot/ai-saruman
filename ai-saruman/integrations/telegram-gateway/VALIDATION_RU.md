## Реализация автономной интеграции, 2026-11-11

Предыдущая таблица фиксирует первый ручной запуск. После него добавлен код
интеграции в игровой runtime и Character Lab. Применение новых возможностей
на настоящем VPS и реальная генерация игровых постов ещё требуют установки
из [AUTONOMOUS_RU.md](AUTONOMOUS_RU.md); по умолчанию публикации выключены.

- 49 тестов шлюза/очереди/генератора: PASS. В том числе полный путь событие →
  модель-имитатор → очередь → настоящий локальный HTTP → Telegram-имитатор;
  сохранение ID после потери ответа, задержка после 429, неопределённая доставка,
  пауза перед отправкой, фильтрация личных сообщений и большие ответы обновлений.
- 21 тест лаборатории: 20 PASS, 1 SKIP. Пропущена проверка настоящей символической
  ссылки: Windows вернула WinError 1314 (нет привилегии создания ссылок).
- 52 теста ролей, 43 теста игрового диспетчера, 1 тест адаптера Telegram: PASS.
  Всего 165 успешных тестов и 1 пропущенный. В старых зависимостях игрового
  окружения остаются предупреждения ResourceWarning про asyncio; ошибок тестов нет.
- Окно Telegram открыто в headless Edge с отдельным временным профилем и
  тестовой SQLite; проверены отрисовка управления/черновика и синтаксис JS.
  Дополнительно проверено HTML-экранирование текста поста. Реальные API/LLM для
  этих проверок не вызывались, сообщения в канал не отправлялись.
- Ключи, `.env.client`, базы и приватный SSH-ключ не добавляются в Git.
- Автоматическая установка на VPS не выполнена: проверка BatchMode SSH вернула
  Permission denied (publickey,password). Пароли и приватные ключи не запрашивались.
  Скрипт setup_tunnel.py должен один раз выполнить владелец с интерактивным входом.

## Исправление Windows stdin при настройке туннеля

Пользователь сообщил `sh: 1: set: Illegal option -` после успешного ввода пароля
VPS. Причина воспроизведена в Windows: `subprocess.run(input=str, text=True)`
передаёт `set -eu\r\n`. Исправленный setup_tunnel.py передаёт UTF-8 bytes с LF.
Добавлены три проверки реального stdin дочернего процесса, повторного использования
ключа и сохранения конфигурации при ошибке SSH. Все 52 теста шлюза/автоматики/
настройки туннеля прошли. Повторная установка на реальном VPS ожидает запуска
команды владельцем; SSH, настоящие ключи и Telegram в этих тестах не используются.
