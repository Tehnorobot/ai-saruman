# Цепочки действий и скриншоты

В Saruman Lab → Управление отправьте, например:

> Посади одно дерево. Затем сделай скриншот и опубликуй пост с ним в канале.

Или:

> Войди в мир «test_3», посади дерево и опубликуй пост со скриншотом.

Lab сохраняет порядок действий, результаты и ID публикации в `.saruman/telegram.sqlite3`.
Принятие игрового поручения не означает успех. Следующий этап начинается после
подтверждения именно этого поручения. Ошибка сохраняется; пост об успехе не отправляется.
После Stop очередь ждёт Start. После перезапуска подтверждённые этапы не повторяются.
Сообщение «Я уже в мире, продолжай задачу» продолжает подходящую незавершённую
цепочку. Для этого не нужен адрес сервера; повторная формулировка не должна
создавать дополнительную посадку. Ошибки связи с API отображаются отдельно от
отсутствия открытого мира. При устаревших Java-ссылках адаптер обновляет их для
чтения состояния; игровые действия после неизвестного результата вслепую не повторяются.
Незавершённое игровое действие наблюдается по сохранённому ID, без слепого повторения.
Если игра сообщила об отмене или неизвестном результате, проверьте её и дайте новое поручение.

В чате видны этапы, их статусы, снимок и номер отправленного сообщения.
Снимок можно запросить отдельно: «Сделай скриншот Minecraft».
Снимается текущий игровой кадр. Ракурс не меняется; камера должна видеть результат.
Открытый чат, инвентарь или меню нужно закрыть. Содержимое рабочего стола не снимается.
Видимый игровой HUD и оверлеи могут попасть в кадр.
Проверенные PNG хранятся в `.saruman/media`, промежуточные — в `.saruman/runtime/captures`.

Для публикации включите Telegram в Lab. Явная просьба опубликовать не требует
флага автоматической публикации. Используется сохранённый канал шлюза; модель
не выбирает адрес, получателя, путь к файлу или команды ОС. Подпись готовит
модель роли Telegram по подтверждённым данным, без приватного диалога.

## Один раз обновить VPS для фото

Локальная часть поддерживает фото. На VPS нужны **gateway.py и media.py** версии API 4.
Старый шлюз продолжает принимать текст. Фото ожидает обновления и не заменяется текстом.

Нажмите Stop в Lab. В PowerShell на своём ПК выполните:

```powershell
cd C:\Users\aimihail\Desktop\projects\ai-saruman\integrations\telegram-gateway
uv run --no-project --python 3.12 python update_gateway.py --server 152.234.255.232
```

Введите пароль VPS только в запросе SSH. Если используете административный ключ,
добавьте `--identity C:\путь\к\ключу`. Ограниченный ключ `telegram-tunnel` не подходит.
Скрипт обновляет два файла, перезапускает существующую службу, проверяет `/healthz`
и возвращает прежние файлы при неуспешном запуске. `.env`, бот, канал и история остаются.
Тестовый пост не отправляется. После сообщения `Gateway API v4 ready` нажмите Start.

Перед повторной отправкой клиент проверяет прежний ID поста. Если ответ Telegram
потерян и результат неизвестен, автоматической повторной публикации нет: проверьте канал.
