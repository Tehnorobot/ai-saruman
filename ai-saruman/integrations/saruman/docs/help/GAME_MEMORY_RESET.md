# Начать знакомство с миром заново

В Gradio открой **Control → Игровая память · начать заново**.

1. Нажми Stop и дождись остановки текущей игровой задачи.
2. Нажми «Сбросить игровую память при перезапуске».
3. Закрой Python runtime через Ctrl+C и снова запусти `scripts/start-saruman.ps1`.

При новом запуске удаляются все накопленные знакомства, ники, диалоги и отношения
из PostgreSQL, настроение возвращается к нулю. Из локальных SQLite удаляются
просьбы и игровые цели; из пространства Сарумана в Redis — контекст, очереди,
сохранённые места и контрольные точки. Очистка выполняется до восстановления
памяти и запуска фоновых процессов, поэтому старые просьбы не возобновятся.

Личность, авторские истории и реплики, голоса, `.env`, вход Codex, настройки
моделей, вероятности занятий и история расхода токенов сохраняются.
Мир Minecraft и инвентарь персонажа остаются прежними. Диагностические файлы
логов остаются на диске; автоматически в память персонажа они не загружаются.

В консоли инструментов доступны локальные команды:

```text
!reset_game_memory
!cancel_memory_reset
```

Вместо кнопки отмены можно использовать вторую команду до перезапуска.
Нажатие Start при запланированном сбросе не включает персонажа:
нужно полностью перезапустить Python либо отменить запрос.

Из терминала с активным окружением проекта можно запланировать сброс командой
`saruman-minecraft reset-memory`, отменить — `saruman-minecraft reset-memory --cancel`.
Эти команды сохраняют только запрос; сама очистка происходит при следующем запуске.

Для очистки нужны доступные PostgreSQL и Redis. При ошибке запрос сохраняется,
а запуск останавливается: после восстановления сервисов повтори запуск.
Уже начатую очистку нельзя отменить — её нужно завершить повторным запуском.

После обновления кода полностью перезапусти runtime, чтобы появился новый раздел.
