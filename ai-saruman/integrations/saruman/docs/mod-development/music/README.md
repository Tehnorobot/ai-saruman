# Музыка в мире Minecraft

Исследование от 2 ноября 2026 для текущего профиля Fabric / Minecraft 1.21.11.
Это проект решения, не реализованный или испытанный аддон.

- [Варианты, форматы, ограничения и этапы реализации](FEASIBILITY.md).
- [Текущая архитектура персонажа](../native-runtime/IMPLEMENTATION.md).

Рекомендуемый старт: клиентский музыкальный аддон, подготовленная сцена из
настоящих note blocks, NBS и простой JSON, одна команда на композицию.
Аудиовоспроизведение через AudioPlayer / Simple Voice Chat — отдельный вариант,
если важнее звучание для слушателей, чем физическая игра на блоках.
