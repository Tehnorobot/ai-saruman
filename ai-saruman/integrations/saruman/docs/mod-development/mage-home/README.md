# Аддон строительства дома

Требования для МАС: [MAGE_HOME_SPEC.md](MAGE_HOME_SPEC.md).
Входной [UnionClef 0.95.61](dependency/unionclef-1.21.11-0.95.61.jar) нужен
для компиляции и реальных клиентских тестов, не является новым аддоном.

Веб-форма Lab загружает только Markdown. Соседняя папка `dependency/` автоматически
не передаётся агентам. Для нового проекта:

1. Загрузить ТЗ, поставить созданное задание на паузу и дождаться `USER_PAUSED`.
2. Скопировать только указанный JAR в
   `Codex-Development-Lab/projects/<project_id>/workspace/libs/`.
   ID проекта можно посмотреть в `GET /api/jobs/<job_id>`.
3. Проверить SHA-256 по ТЗ и продолжить задание. Путь внутри рабочего проекта:
   `libs/unionclef-1.21.11-0.95.61.jar`, Fabric mod ID — `altoclef`.

Наличие JAR рядом с исходным ТЗ не заменяет этот шаг. Дополнительные подключения
папок игры или Saruman к контейнерам не нужны.

ТЗ фиксирует дом 7×7×5, три палитры, точные координаты обстановки,
проверку участка, правило 100 блоков, реестр и возобновление строительства
после устранимых ошибок без пожизненных лимитов попыток. Автоматическое обнаружение
повреждений в фоне не требуется; проверка — при `status` и `resume`.
Серверный мод не нужен. Статус: спецификация, Mage Home ещё не реализован.
