# Auto Defense — документы для создания мода

Для фактической интеграции новых Auto Defense 1.0.0 и TreeGrow 0.1.0 от 24 октября
2026 использовать [проверку текущих модов и архитектуры](../native-runtime/README.md).
Материалы ниже — предыдущий проектный план; они не описывают фактические Java API
новых JAR и не отменяют более новые ТЗ владельца в Codex-Development-Lab/examples.

Все актуальные материалы по этому моду находятся в этой папке. Ранее они лежали
в docs/dev; теперь использовать пути docs/mod-development/auto-defense.

| Порядок | Документ | Назначение |
|---|---|---|
| 1 | [AUTO_DEFENSE_SPEC.md](AUTO_DEFENSE_SPEC.md) | Основное ТЗ универсального мода: функции, API, независимость от Saruman, приёмка |
| 2 | [AUTO_DEFENSE_IMPLEMENTATION_GUIDE_1_21_11.md](AUTO_DEFENSE_IMPLEMENTATION_GUIDE_1_21_11.md) | Правила реализации именно под Minecraft Fabric 1.21.11, ввод, синхронизация, проверки |
| 3 | [SARUMAN_AUTO_DEFENSE_SPEC.md](SARUMAN_AUTO_DEFENSE_SPEC.md) | Профиль персонажа, адаптер UnionClef и план подключения к текущей системе |

Для разработки универсального мода передать разработчику первые два документа.
Третий добавить при реализации совместимости с Saruman/UnionClef. Боевой код
универсален; правила и конкретные зависимости персонажа остаются в интеграции.

Эти документы описывают будущую реализацию. Они не подтверждают готовность,
компиляцию, установку или игровые испытания нового JAR.

Новые материалы этого мода добавлять сюда. Документы других будущих модов
складывать в отдельные папки docs/mod-development/<mod-name>/ с собственным README.
Дневники выполненной работы остаются в docs/ai и не являются инструкциями для сборки.
