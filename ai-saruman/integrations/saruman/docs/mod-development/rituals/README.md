# Клиентский мод магических ритуалов

Для разработки передать один файл: [RITUALS_SPEC.md](RITUALS_SPEC.md),
редакция от 3 ноября 2026. Она заменяет прежний серверный вариант.

Четыре однократных эффекта через vanilla-команды. JAR нужен только клиенту
персонажа; серверу и другим игрокам устанавливать ничего не требуется.
Необходимы права на particle/playsound. Статус: ТЗ, клиентский мод ещё не создан.

[Проверки подключения к Саруману](SARUMAN_INTEGRATION_CHECKLIST.md) выполняются
владельцем отдельно и не входят в задачу разработчика мода.
