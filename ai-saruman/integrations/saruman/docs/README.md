# Generating the docs

----------

Use [mkdocs](http://www.mkdocs.org/) structure to update the documentation.

Go to the `docs/` folder:

    `cd docs/`

Deploy to GitHub Pages with:

    `mkdocs gh-deploy`

Дополнительно:

Build locally with:

    `mkdocs build`

Serve locally with:

    `mkdocs serve`

Сейчас публикуемые доксы лежат в `docs/help/`, начальный файл в `index.md`

Материалы для создания модов хранятся отдельно в `docs/mod-development/<mod-name>/`.
Начать с [документов Auto Defense](mod-development/auto-defense/README.md).
Актуальная оценка готовых модов от 24 октября 2026:
[переход персонажа на native runtime](mod-development/native-runtime/README.md).
