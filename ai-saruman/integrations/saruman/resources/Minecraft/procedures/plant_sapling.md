# plant_sapling — только посадить саженец

Применяй для просьб посадить дуб/берёзу. Эта задача не разрешает расход костной муки.
Если запросили только найти место, выполни лишь поиск и верни координаты — не сажай.

## Заданное количество и самостоятельные цели

Если нужно посадить N дубов/берёз, включая выбранную тобой цель, используй
`manage_trees(count=N, mode="plant", sapling="oak_sapling")`. Не заменяй такую задачу
схемой одного саженца ниже. Для «нескольких» без точного числа выбери разумное
конкретное количество и передай его в count; явное число оператора менять нельзя.

Инструмент сохраняет план и progress: requested/completed/remaining. Сам проверяет
материалы для оставшихся посадок, резервирует разные места с интервалом минимум
4 блока, выполняет одну посадку за вызов и проверяет её. Уже существующий саженец
не считается новой посадкой. Принятие команды сбора/движения не меняет completed.

Следуй next_action: obtain_item/agent_action, дождись завершения, затем снова вызови
manage_trees с теми же аргументами. При in_progress сразу продолжай manage_trees.
Нормальный результат для двух деревьев: 0/2 → 1/2 → 2/2; завершение — только
status=completed. При blocked сообщи подтверждённое количество и причину.
Состояние видно в get_game_status().tree_task. Продолжения действуют и без
операторского задания: самостоятельный вызов создаёт продолжение агента.
При явном «Продолжи» читай сохранённый tree_task и передавай прежний config,
new_task=false. После перезапуска Python координаты и прогресс остаются в Redis;
paused возобновляется, отменённая цель требует явного продолжения оператора.
Работай в том же мире; возвращайся к сохранённой точке короткими наблюдаемыми
переходами. Если проход не подтверждён, сообщи причину, не обнуляй результат.
manage_trees проверяет другие сохранённые цели и может заменить ещё не выполненный
план доступным местом. Уже посаженные деревья и общий счётчик сохраняются.
После blocked без next_action не объявляй, что проверка уже продолжается.

Нельзя переключаться на одиночные действия в обход активного счётчика.
Повтор completed не сажает лишние деревья. new_task=true применяй только для новой
самостоятельной цели, а не для обхода блокировок/лимитов. Stop отменяет продолжение
и сохраняет частичный результат; новое операторское задание заменяет старую цель.
Задача ограничена 1..32 деревьями, 20 минутами и конечным числом шагов.

## Одна посадка через отдельные инструменты

1. Прочитай `get_inventory()`. Если саженца нет, вызови
   `obtain_item("oak_sapling", 1)` и дождись завершения сбора. Не повторяй активный `@get`.
2. Вызови `find_tree_planting_spots(sapling="oak_sapling")` один раз.
   Используй координаты из результата, не угадывай их по текстовому описанию мира.
3. Выбери ближайшую точку с `within_reach=true`. Вызови
   `plant_sapling(x, y, z, sapling="oak_sapling")`: y — клетка саженца над почвой.
   Инструмент проверяет правила растения, политику установки, пространство,
   инвентарь и прицел, выполняет один клик и проверяет появление саженца.
4. Только `planted=true` подтверждает посадку. Already_present означает, что саженец
   уже был в этой точке; не приписывай себе повторную посадку.

Если точек нет, выполни `exploration.next_action`, если он предложен: перейди в новый
участок, дождись прибытия и вызови find_tree_planting_spots снова. Поиск запоминает области;
по умолчанию разрешено до 4 переходов и до 128 кандидатов за обзор. `search_steps`
можно задать 0..8, `candidate_limit` — 24..256; сохраняй выбранные пределы при продолжении.
Если движение запрещено оператором, search_steps=0 и не выполняй команды подхода.
Для уже найденного места используй `approaches[].command`, затем проверь новые точки.
Не выдавай точку будущего ствола за безопасное место для стояния. Если проход неясен,
сообщи препятствие, а не придумывай координаты или бесконечный поиск.
Отказ после одного пустого обзора при доступном exploration.next_action преждевременен.
Если следующего действия нет, сообщи exploration.status и rejected: ограничение пути,
исчерпанный бюджет или причины отсева мест; не утверждай, что травы нигде нет.
Y команды — высота ног над полом на Y-1; не прибавляй единицу к высоте саженца.
Опора и проход проверяются через коллизии и опасность блоков Minecraft; почва —
через нативное правило саженца, пространство — через проверку обычного дерева.
Путь может идти вброд или по поверхности воды с воздухом над головой, без ныряния.
Не объявляй воду непреодолимой только по названию блока. Полублоки с дробной высотой
ног пока не поддерживаются. Найденное место не гарантирует рост с одной дозы муки.
При navigation=blocked проверь досягаемые места рядом или выбери другой подтверждённый
подход; не повторяй проваленную цель. При stop_failed сообщи, что остановка не подтверждена.

При `waiting_for_game_task` дождись текущей задачи. При неизвестном результате клика
сначала осмотри точку и инвентарь; не дублируй установку автоматически. Не сажай на
песчаник, песок или постройки и не заменяй занятые клетки. Сценарий поддерживает
одиночные oak_sapling/birch_sapling, не деревья с обязательной схемой 2×2.
