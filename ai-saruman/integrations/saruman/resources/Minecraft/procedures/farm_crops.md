# farm_crops — посадка и сбор урожая для еды

Используй farm_crops(mode="auto"), plant — только посадить, harvest — только зрелый сбор.
Каждый вызов выполняет максимум одно физическое действие. Это не ожидание созревания.
Поддерживаются пшеница, морковь, картофель и свёкла. Зрелость проверяет сам Minecraft.
Молодые растения не ломай. Костная мука, полив и дежурство возле грядки не нужны.

Семена и посадочные морковь/картофель получай только из спелого урожая через
farm_crops. Если семян нет, plant тоже сначала собирает зрелое растение.
Не используй @get семян/пшеницы/моркови/картофеля или @mineblock урожая: штатный
сбор не гарантирует сохранность молодых посадок. Эти обходы заблокированы.
При waiting_for_growth оставь грядки расти и выбери другое дело; вернись позже.
Если семян и спелого урожая нет, ищи зрелые растения в другом месте.
no_work описывает только текущий снимок радиуса 5, не весь мир. Смотри reason_code
и scan: нет семян/зрелых растений, воды, пригодной почвы или доступного прохода.
Для нового участка используй explore_nearby(purpose="farm", search_steps=4);
при исчерпании покрытия бюджет расширяется 4 → 8 → 16 → 32 → 64 переходов по суше
(предел задаёт SARUMAN_SEARCH_MAX_MOVES). Следуй
только наблюдаемой next_action, дождись движения и повтори farm_crops на новом месте.
Фоновый планировщик выполняет это через очередь, между попытками выбирая другие дела.
Песок не годится для этих культур; наличие земли не заменяет семена, воду и доступ.
При needs_materials next_action.obtain_item нужен только для мотыги на новой земле.
Выполни его один раз и дождись native-задачи.
При needs_move используй только наблюдаемую next_action.agent_action, дождись пути.
Не ставь воду и не ломай постройки, не проходи повторно проваленный маршрут.
Результат planted/tilled требует появления соответствующего блока. harvested означает
убранное зрелое растение; collected отдельно показывает подтверждённый прирост инвентаря.
Подойди к выпавшим предметам через предложенный проход; не выдавай их за подобранные
до чтения get_inventory. Если путь или видимость не подтверждены, выбери другое дело.

Ешь свои припасы через eat_food при голоде, сохраняя последний посадочный картофель/
морковь. Из трёх уже собранных wheat можно получить bread через obtain_item("bread", 1).
Недостающую пшеницу для хлеба собирай только через farm_crops; штатный @get bread
не запускается без достаточных припасов, чтобы не добывать молодые посадки скрыто.
Еда восполняет голод, восстановление здоровья зависит от игровых правил; проверяй
get_inventory. При полном голоде обычную еду не используй. Не добывай мясо у животных.
Неизвестный результат взаимодействия не повторяй вслепую: сначала осмотри место.
После обычного no_work/blocked фоновый выбор переключит занятие с сохранением целей.
