# Mage Home — строительство домов из Saruman Lab

Mage Home переводит описание дома в схему, подбирает и готовит участок,
строит в Minecraft и сверяет результат с чертежом. Saruman Lab принимает
поручение, передаёт управление строительному адаптеру и показывает прогресс.
По запросу Lab делает внешний снимок готового дома и публикует отчёт.

## Установка

| Компонент | Проверенная версия | Где используется |
| --- | --- | --- |
| Minecraft Java Edition и Java | Minecraft **1.21.11**, Java **21** | Игра в клиентском профиле TLauncher или другого лаунчера |
| Fabric Loader | **0.19.2** | Выбирается при запуске профиля |
| Fabric API | `fabric-api-0.141.3+1.21.11.jar` | Устанавливается в `mods` этого профиля |
| UnionClef | `unionclef-1.21.11-0.95.61.jar` | Общий клиентский мод. Предоставляет игровое управление и локальный мост Py4J |
| Mage Home | `mage_home-0.1.10.jar` | Клиентский исполнитель стройки и камера для снимков готового дома |

Для строительства из набора аддонов достаточно **UnionClef и Mage Home**.
Fabric Loader и Fabric API нужны для запуска модов. TreeGrow и Auto Defense
подключаются к Lab отдельно для посадки деревьев и защиты. Их можно включать,
если эти навыки нужны персонажу во время стройки. Остальные клиентские моды
из полного профиля можно выбирать по своим задачам.

1. Скачайте Fabric API, UnionClef и Mage Home из [папки сборок на Google Drive](https://drive.google.com/drive/folders/1f9qnsgq9a7K60Pik4RcNofuciat_58Kh?hl=ru).
2. Закройте Minecraft и положите JAR-файлы в `mods` нужного профиля. В
   Windows стандартный путь TLauncher — `%APPDATA%\.minecraft\mods`.
   Если в лаунчере указан отдельный каталог игры, используйте его `mods`.
   Оставьте по одной версии каждого мода.
3. Подготовьте окружения по [инструкции запуска Saruman](../integrations/saruman/docs/SARUMAN_WINDOWS.md)
   и откройте [Saruman Lab](http://127.0.0.1:8765). Игровому обработчику
   нужна среда с Py4J. Для первого снимка Lab компилирует локальный мост, поэтому
   `javac` из JDK 21 или новее должен быть доступен в `PATH`.
4. Запустите Minecraft с выбранным профилем. Откройте одиночный мир или зайдите
   на обычный сервер. Установка серверного расширения для Mage Home не требуется.
   В Lab нажмите **Start** и включите **Mage Home** в разделе **Моды и адаптеры**.

Проектировщик и эксперт версии **0.6.6** уже лежат в исходниках репозитория.
Lab подключает их из `integrations/mage-home/python/`. Отдельный wheel нужен
только для поставки адаптера без исходников. Сборка JAR из исходников описана
в [README компонента](../integrations/mage-home/README.md).

## Поручения и проверка запуска

| Поручение в разделе «Управление» | Что проверить |
| --- | --- |
| «Построй тестовый дом» | Готовая схема 7×7 проверяет подключение, выбор участка и работу исполнителя без вызова проектировщика |
| «Построй двухэтажный дом с окнами, спальней, кухней и уютным интерьером» | Модель проектирует по описанию. Если координаты опущены, участок выбирает адаптер |
| «Построй еловый дом X 120, Y 64, Z 200» | Используется заданная точка привязки. Исполнитель проверяет участок перед изменениями |
| «Как идёт стройка?» / «Поставь стройку на паузу» | Lab показывает состояние конкретного запуска или освобождает управление с сохранением прогресса |
| «Покажи мои дома» / «Дострой дом prj-…» | Открывается каталог. Указанный проект продолжается в его мире |
| «Останови стройку» | Текущий запуск останавливается. Поздний ответ модели его не возобновляет |
| «Зайди в мир „Учебный“, построй двухэтажный дом и опубликуй отчёт со скриншотом» | Lab подтверждает нужное сохранение, стройку, снимок, черновик и доставку в Telegram |

Для команды входа укажите точное имя папки существующего одиночного мира.
Для публикации включите и настройте Telegram. Составное поручение публикуется
только после подтверждения готовности и получения снимка. Подробности входа,
управления и очереди доставки есть в [инструкции автономности](AUTONOMY_RU.md).

## Как работает модуль

```text
Управление в Lab
  → адаптер Mage Home → подтверждение мира и передача управления
  → поиск участка или заданные координаты
  → проектировщик → проверяемый чертёж
  → Minecraft: подготовка → стройка → сверка → уборка → выход
  → READY → снимок дома → черновик → публикация, если запрошена
```

1. **Проектирование.** Модель переводит текст в план этажей, комнат, проходов,
   крыши, материалов и мебели. Компилятор проверяет блоки и их состояния,
   опоры, ориентацию, обязательные требования и доступность используемых зон.
   Лестницы получают свободный объём для шага и подъёма. Для прямоугольного
   верхнего этажа от 5×5 блоков выбирается двускатная крыша, если тип не задан.
   Расстановка и палитра обстановки учитывают назначение комнат и меняются
   между новыми проектами. Провайдеры и модели проектировщика и игрового
   эксперта настраиваются независимо. [Компилятор](../integrations/mage-home/python/mage_home/blueprint.py) · [Интерьер](../integrations/mage-home/python/mage_home/interior.py) · [Проектирование и правки](../integrations/mage-home/python/mage_home/__main__.py)
2. **Подготовка и исполнение.** Поиск оценивает расчистку и засыпку на
   загруженных участках до 112 блоков от персонажа и учитывает занятые
   площадки. Исполнитель физически ставит и ломает блоки, ходит между точками
   работы и при необходимости использует леса. `/give` пополняет инвентарь,
   если право доступно. Для сложного доступа используются смена стороны,
   внешняя точка подхода и временный проём с восстановлением. `READY`
   фиксируется после сверки мира, уборки временных конструкций и выхода
   персонажа. [Поиск участка](../integrations/saruman/resources/Minecraft/bridge/ModGateway.java) · [Подготовка](../integrations/mage-home/src/main/java/dev/magehome/v5/engine/SiteSurvey.java) · [Исполнитель](../integrations/mage-home/src/main/java/dev/magehome/v5/engine/ProductionBuildEngine.java) · [Игровые действия](../integrations/mage-home/src/main/java/dev/magehome/v5/engine/ServerActions.java)
3. **Восстановление.** Игровой эксперт получает цель, снимок состояния блоков
   и историю успешных, неудачных и прерванных попыток. Он может запросить
   наблюдение, предложить проверенный подход, леса или локальную правку
   чертежа. Исполнитель сверяет мир, поколение запуска и права управления
   перед применением ответа. Когда допустимые варианты исчерпаны, Lab
   показывает сохранённую паузу или блокировку с причиной. [Эксперт](../integrations/mage-home/python/mage_home/expert.py) · [История проектирования](../integrations/mage-home/python/mage_home/design_history.py) · [Журнал строительства](../integrations/mage-home/src/main/java/dev/magehome/v5/engine/BuildJournal.java)
4. **Управление и хранение.** Адаптер обнаруживается по манифесту. В Lab можно
   отдельно включать навыки, обновлять их доступность и задавать веса фоновых
   занятий. Приоритет идёт от команды оператора к просьбе игрока, реактивной
   защите, обычным задачам и фоновому выбору. Временное вытеснение может
   вернуть управление той же стройке. Ручная пауза ждёт явного продолжения.
   Новый запрос создаёт отдельный проект, а повтор доставки прежнего запроса
   сохраняет его ID. Метаданные и этапы Lab лежат в локальной SQLite,
   контрольные точки стройки — в `config/mage_home/build-journals/`
   игрового профиля. [Манифест](../adapters/mage_home/adapter.json) · [Адаптер](../adapters/mage_home/adapter.py) · [Мост](../adapters/mage_home/bridge.py) · [Координация навыков](../src/saruman/extensions.py)
5. **Снимок и отчёт.** Цепочка берёт координаты из подтверждённого проекта.
   Клиентская камера подбирает ракурс на дом и крышу без перемещения
   персонажа. Если объект перекрыт рельефом или недоступен в загруженной
   области, Lab показывает причину и не отправляет отчёт с пустым кадром.
   Каталог объекта и отчёт используют один подтверждённый снимок.
   [Цепочки Lab](../src/saruman/workflows.py) · [Камера](../integrations/mage-home/src/main/java/dev/magehome/client/CompletionPhoto.java) · [Мост снимков](../integrations/saruman/src/saruman/screenshot.py)

## Диагностика и границы

- **Lab пишет «Ожидает мир».** В окне **Готовность** проверьте Minecraft,
  игровой мост, включённые моды и профиль модели. Для составной команды
  Lab ждёт свежего подтверждения нужного мира. Новый запрос на другой мир
  выполняется из главного меню Minecraft. [Проверки готовности](../src/saruman/readiness.py) · [Подключение к миру](../src/saruman/game_connection.py)
- **Участок или чертёж отклонён.** Автопоиск принимает размеры площадки
  от 3×3 до 32×32 блоков. Компилятор допускает до 96 блоков по оси, до
  65 536 клеток в ограничивающем объёме и суммарно до 8 192 целевых и
  обязательных пустых клеток. Доступность конкретного места зависит от
  загруженного рельефа, прав, материалов и возможности физически выполнить
  схему. [Схема чертежа](../integrations/mage-home/spec/blueprint-schema-v5.json) · [Проверки границ](../integrations/mage-home/python/mage_home/blueprint.py)
- **Предупреждение UnionClef о привате.** В одном проверенном запуске
  бочка была успешно сломана, но UnionClef проверил координату после
  повторной установки и увидел уже новую бочку. Поэтому по одной фразе
  `Maybe private area` нельзя определить причину остановки. Для вывода
  сверяйте исход игрового действия в журнале. Физическое ломание
  отправляет ванильные пакеты и может выглядеть мгновенным без анимации.
  [Обработка действия ломания](../integrations/mage-home/src/main/java/dev/magehome/v5/engine/ProductionBuildEngine.java) · [Пакеты клиента](../integrations/mage-home/src/main/java/dev/magehome/v5/engine/ServerActions.java)
