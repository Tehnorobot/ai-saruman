# Saruman · агенты и лаборатория

Локальная лаборатория для тестирования ИИ-персонажа Minecraft: чат, память,
граф сущностей, история диалогов и аналитика использования моделей.

Игровой runtime Сарумана находится в
[`integrations/saruman/`](integrations/saruman/). Это обычные файлы этого
репозитория, не submodule и не отдельный fork.

## Minecraft: с чего начать

Для запуска на Windows открой
[инструкцию Сарумана](integrations/saruman/docs/SARUMAN_WINDOWS.md).
Все команды игры выполняй из `integrations/saruman/`, например:

```powershell
cd C:\Repos\ai-saruman\integrations\saruman
.\scripts\start-saruman.ps1 -Doctor
```

Сначала выполни подготовку окружения и сервисов из инструкции.
Лаборатория использует Python 3.14+, игровой runtime — Python 3.10.9–3.10.x.
У них отдельные `.venv` и lock-файлы: не устанавливай оба проекта в одно окружение.
Общий интерфейс и автоматический запуск игры из лаборатории пока не добавлены.

[Структура, происхождение кода и правила работы с одним репозиторием](docs/MONOREPO.md).

## Telegram: отдельная проверка связи

Подготовлен [текстовый шлюз и инструкция для VPS](integrations/telegram-gateway/README_RU.md).
Реальная отправка с компьютера через VPS и защита от дублей проверены пользователем.
[Автономные публикации персонажа и окно Telegram](integrations/telegram-gateway/AUTONOMOUS_RU.md)
подключают игровые события, отдельную модель Telegram, очередь, историю и SSH-туннель.
Окно: `http://127.0.0.1:8765/#telegram`. Включение и автопубликация задаются отдельно;
по умолчанию они выключены. Для новых API требуется обновить gateway.py на VPS.

## Выбор LLM по задачам

Открой **Настройки**: http://127.0.0.1:8765/#settings.
У чата Lab, персонажа, игровых действий и Telegram независимые провайдер,
модель и reasoning. Старые агенты и дополнительные инструменты находятся
в свёрнутом разделе. Выбор не включает эти инструменты автоматически.

Поддерживаются Codex / ChatGPT, MiniMax M Plan, LiteLLM и DSLab / Claude.
Настройки общие для Lab и игрового runtime: `integrations/saruman/data/role-models.sqlite`.
Они применяются со следующего запроса; текущий запрос защищён от смены модели.
Ключи укажи в `integrations/saruman/.env.saruman`. Для MiniMax:

```dotenv
MINIMAX_API_KEY=ваш_Subscription_Key
MINIMAX_BASE_URL=https://api.minimax.io/anthropic
```

Для M Plan Explore нужен **Subscription Key** из Plan Details, не обычный
pay-as-you-go ключ. Модель: `MiniMax-M3.1-Flash`; reasoning:
`default`, `low`, `medium`, `high`, `xhigh`, `max`. `default` означает `max`.
[Подробности, роли и проверка](docs/MODEL_SETTINGS_RU.md).

При первом обновлении останови старые Python-процессы Lab и игры, затем
запусти их заново. Minecraft перезапускать не требуется. После изменения ключей
тоже перезапусти оба Python-процесса. Браузер не получает ключи.

Начальные настройки Codex берутся из шаблона:

В `integrations/saruman/.env.saruman.example` задано:

```dotenv
CORE_LLM_MODEL_NAME=codex/auto
```

Конкретная LLM не закреплена: адаптер запрашивает каталог моделей Codex,
выбирает модель с `isDefault`, а если такой нет — первую доступную запись.
`Codex` здесь обозначает backend, а не имя конкретной модели.

После клонирования создай локальный `integrations/saruman/.env.saruman` из
шаблона и заполни настройки. Для закрепления модели замени `auto` точным ID
из каталога. Локальный `.env.saruman` исключён из Git и не переносится при clone.
После сохранения роли в Lab приоритет имеет её профиль в общей базе.

Подробности и пример: [LLM Сарумана](integrations/saruman/README.md#llm-сарумана).

## Запуск лаборатории

Нужен Python 3.14 или новее. Для интерфейса не нужны Node.js и сторонние Python-пакеты.

Из корня репозитория:

~~~bash
PYTHONPATH=src python3 -m saruman
~~~

Открой http://127.0.0.1:8765. Для другого порта:

~~~bash
PYTHONPATH=src python3 -m saruman --port 8766
~~~

Если проект уже установлен в виртуальное окружение, доступны команды
saruman и python -m saruman. Параметр --project /absolute/path/to/ai-saruman
позволяет указать корень проекта при запуске из другой папки.

## Подключение моделей по подписке

1. Установи актуальный Codex CLI, если его ещё нет, и выполни codex login.
   Выбери вход через ChatGPT, а не API-ключ.
2. Запусти лабораторию на том же компьютере и под тем же пользователем.
3. Нажми «Подключить Codex». Приложение запросит аккаунт, каталог моделей и лимиты.
4. Выбери модель. Наличие модели в каталоге не гарантирует право доступа:
   его подтверждает только успешно выполненный запрос.
5. Напиши сообщение или выбери сценарий. Сценарий лишь подставляет текст —
   отправка выполняется отдельно кнопкой «Отправить».

Лаборатория запускает установленный codex app-server по stdio. Он использует
свою существующую авторизацию и обновляет её самостоятельно. Приложение
не читает auth.json, не передаёт токены в браузер и не использует API-ключи.
При отсутствии ChatGPT-авторизации показывается ошибка вместо переключения
на платный API.

Вызовы модели расходуют лимиты подписки. Проверка подключения не запускает
генерацию, но обращается к сервисам Codex. Тесты используют подставной
провайдер и не обращаются к настоящей модели.

## Окна интерфейса

- **Тестирование** — последовательный чат, выбор модели, шесть сценариев,
  информация о последнем ответе. Новый диалог очищает историю разговора,
  но читает общую долговременную память.
- **Память** — интерактивный граф связей из двойных Markdown-ссылок,
  таблица сущностей, просмотр исходных файлов и таблиц SQLite.
- **Диалоги** — сохранённые сессии, полная последовательность реплик,
  экспорт выбранного диалога и его запросов в JSON.
- **Аналитика** — токены каждого запроса, вход/выход, кэш, задержка,
  дневной график, окна лимитов и оценка вклада памяти в контекст.
- **Подключение** — статус аккаунта, инструкция запуска и просмотр личности.

## Как работает память

Источником истины остаётся agent-workplace/agent/saruman/memory/.
Чат использует текущую PERSONA.md, память и историю выбранного диалога.
Автономные GOALS.md и SESSION_PROMPT.md относятся к игровому раннеру;
в тестовом чате их инструкции по выполнению действий не запускаются.

По умолчанию запись выключена. Чтобы проверить долговременную память,
включи «Запоминать факты» и, например, представься персонажу. Ответ модели
содержит отдельные структурированные предложения для памяти. Раннер
проверяет их формат и записывает факты в Markdown со ссылкой на тестовую
сессию и запрос, обновляет обратные связи и индекс.

Память общая для всех тестовых сессий. Записи из тестов отмечены как
character lab и не означают, что событие действительно произошло в Minecraft.
Модель может ошибаться в содержании фактов: проверяй их во вкладке файлов.
Личность, цели и состояние мира модель в этом чате не редактирует.

Чат не запускает игровые или shell-инструменты. Сессии Codex создаются
эфемерными с отключённым доступом к средам, shell, приложениям и плагинам;
неожиданные запросы инструментов клиент отклоняет. История и метрики
сохраняются лабораторией в .saruman/lab.sqlite3, исключённой из Git.

## Что означают «затраты» и «заполненность»

Не все интересующие показатели провайдер предоставляет в денежном виде.

| Показатель | Откуда берётся |
| --- | --- |
| Вход, выход, кэш, reasoning и всего токенов | Уведомления thread/tokenUsage/updated. Для нового эфемерного thread берётся итог total, без суммирования повторных уведомлений. |
| Лимиты подписки и время сброса | account/rateLimits/read. Окна общие для аккаунта и могут учитывать другие приложения; обновляются кнопкой подключения. |
| Денежная стоимость ответа | Не предоставляется для подписки; показывается «—», а не $0 и не API-тариф. |
| Вклад памяти, инструкций и истории | Оценка по длине текста: символы / 4. Служебный контекст Codex не включён. Это не точная токенизация и не отдельное списание. |
| Запись новых фактов | Выполняется в том же ответе модели; оценка размера выходного JSON памяти. Отдельного скрытого модельного вызова нет. |
| Размер памяти | Фактический размер Markdown-файлов в байтах. |
| Рекомендация state.md | 16 КБ из шаблона; это сигнал к сжатию, а не жёсткая ёмкость памяти или контекстное окно модели. |

Reasoning уже входит в выходные токены, кэш — во входные. Эти величины
не прибавляются к сумме повторно. Неизвестные метрики сохраняются как NULL
и отображаются как «—». Ошибки, включая достижение квоты, сохраняются
отдельно; известный расход ошибочного запроса также учитывается.

## Архитектура и следующий шаг

src/saruman/web.py обслуживает локальный интерфейс, storage.py хранит
диалоги и статистику, memory.py читает и обновляет память, provider.py
управляет Codex app-server. Статические файлы лежат в src/saruman/static/.

Здесь есть важное различие:

- **Свой интерфейс и управление контекстом поверх Codex** — текущая реализация.
  Готовый агентный runtime предоставляет app-server; лаборатория управляет
  личностью, историей, записью памяти и учётом использования.
- **Полностью собственный agent loop** — отдельный следующий этап:
  Sign in with ChatGPT для локального приложения плюс Responses API.
  Это позволит самому реализовать вызовы инструментов и цикл действий.

Игровой автономный цикл, наблюдения, действия и голос сохранены в
`integrations/saruman/`. Лаборатория пока не управляет этим runtime и не синхронизирует
с ним всю память. Для Telegram есть отдельный общий журнал событий/постов и сигнал
состояния игрового runtime. Контракты лаборатории находятся в
`agent-workplace/agent/saruman/TOOLS.md`. Публикации Telegram используют выбранную
игровую модель PersonaAgent; видеопубликации и интеграция YouTube пока не подключены.

Официальные источники, проверенные 17 октября 2026 года:

- [Codex app-server: протокол, авторизация, токены и лимиты](https://learn.chatgpt.com/docs/app-server)
- [Использование плана ChatGPT в локальных и open-source приложениях](https://developers.openai.com/siwc/token-sharing-open-source)
- [Ограничения Sign in with ChatGPT](https://developers.openai.com/siwc/token-sharing-open-source/preview-limitations)

## Проверки

~~~bash
PYTHONPATH=src python3 -B -m unittest discover -s tests -v
python3 -B agent-workplace/tools/check.py
~~~

Сервер слушает только 127.0.0.1. Локальные POST-запросы проверяют Origin,
Host и случайный токен сессии. Публичное размещение и многопользовательская
авторизация в эту версию не входят.
