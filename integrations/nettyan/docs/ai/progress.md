# Прогресс

Рабочий файл: сюда пишется ход текущей задачи по структуре IPI
(Investigate -> Plan -> Implement). Формат и правила — в `readme.md` рядом.
Когда файл переваливает за 500 строк или задача закрыта, он уезжает
в `archive/` под именем `DD-MM-YYYY-task-name.md`.
