# Настройки Сарумана

Рабочая папка — `integrations/saruman`. Основной файл настроек — `.env.saruman`.
Скопируй `.env.saruman.example`, только если локального файла ещё нет.
`.env.example` содержит те же значения для совместимости с прямым запуском.
Переменные процесса имеют приоритет; затем `.env.saruman`, `.env`, `.env.postgres`.

## Персонаж

```dotenv
SARUMAN_CHARACTER_NAME=Saruman
```

Профиль: `resources/Characters/Saruman/`. Имена, псевдонимы и доверенные операторы
задаются в `char_config.yml`; список `GodUsers` изначально пуст. Не добавляй туда
обычных игроков. Личность находится в `personalities.yml`, голос — в `Voice/`.

## LLM по подписке ChatGPT

```dotenv
CORE_LLM_MODEL_NAME=codex/auto
VISION_LLM_MODEL_NAME=NONE
EMBEDDINGS_MODEL=NONE
```

Выполни `codex login` через ChatGPT в Windows. `auto` выбирает default из каталога;
для закрепления модели укажи `codex/<точный-ID>`. Нет автоматического перехода
на API-ключ. Доступ и расход лимитов подтверждаются реальным запросом.
Другие провайдеры сохранены в коде для отдельной явной настройки.

## Голос: Rich

Fish Speech 1.5.1 работает на NVIDIA GPU, Parakeet TDT v3 0.6B INT8 — на CPU
в отдельном контейнере. `STT_COMPUTE_DEVICE` относится к локальному Whisper,
а не к серверу Parakeet. Голосовые образцы пока тестовые; замена описана в
[инструкции](instructions/SOUNDS.md).

Адреса по умолчанию: TTS `http://127.0.0.1:22231/`, STT
`http://127.0.0.1:22233/v1/audio/transcriptions`, streaming STT
`ws://127.0.0.1:22233/v1/audio/stream`. Укажи реальные имена аудиоустройств
и пароль OBS. Проверяй отсутствие самоподслушивания синтезированного голоса.

## Сервисы и данные

Задай уникальный `POSTGRES_PASSWORD`. По умолчанию БД и пользователь — `saruman`.
Compose и Python должны читать один `.env.saruman`. Память PostgreSQL хранится
в томе `saruman_saruman_db`; переименование кода не переносит старые БД автоматически.
Redis использует ключи `saruman:`; это оперативный контекст, а не долговременная память.

Twitch и другие социальные сервисы включаются отдельно после заполнения собственных
учётных данных. Чужие каналы и учётные записи в шаблоне не заданы.

Полная последовательность запуска: [Windows-инструкция](../SARUMAN_WINDOWS.md).
