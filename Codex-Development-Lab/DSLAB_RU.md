# Claude через DSLab

Панель поддерживает `codex` и `dslab`. Существующие задания сохраняют Codex до явного изменения настроек. DSLab использует нативный Anthropic Messages API, а не Codex CLI.

## Настройка

Добавь в локальный `.env`:

```dotenv
DSLAB_API_KEY=твой_ключ_DSLab
DSLAB_BASE_URL=https://api.dslab.tech
DSLAB_CONTROL_TOKEN=отдельная_случайная_строка_минимум_32_символа
```

`DSLAB_CONTROL_TOKEN` — внутренний секрет этого Lab, не ключ DSLab. Создать его в PowerShell:

```powershell
$dslabBytes = New-Object byte[] 32
[Security.Cryptography.RandomNumberGenerator]::Create().GetBytes($dslabBytes)
[Convert]::ToBase64String($dslabBytes)
```

Скопируй полученную строку в `.env`. Не меняй её между обычными перезапусками. Файл `.env` не подключается к агентам и не попадает в Docker build context.

Если контейнеры уже обновлены, после изменения `.env` пересоздай получателей настроек. Сначала поставь задание на паузу и дождись статуса `USER_PAUSED`:

```powershell
docker compose up -d --no-deps --force-recreate provider-gateway dashboard worker agent-dslab
```

Для новой установки используй `START_WINDOWS.ps1`: он собирает образы, проверяет изоляцию и создаёт тома. Не запускай обновление обработчика во время активного раунда.

В панели `http://localhost:8080`:

1. Выбери существующий проект. Исходники, раунды и ТЗ сохраняются.
2. Открой «Изменить модель / reasoning для следующих циклов».
3. Выбери **DSLab / Claude API**, затем `claude-sonnet-5-5` или `claude-opus-5-5`.
4. Выбери effort и лимиты. Нажми «Сохранить», затем «Продолжить».

Проверка ключа и реальный запрос произойдут при запуске задания. Платные запросы не выполняются при открытии страницы, сохранении настроек или просмотре расхода. Подписка ChatGPT не оплачивает DSLab.

## Расход

Отдельная карточка **«Расход токенов · DSLab»** обновляется каждые две секунды. Кнопка открывает окно с историей запросов. Доступен также `GET /api/jobs/{job_id}/usage`.

Показываются входные и выходные токены, запись и чтение кеша, сумма токенов и оценка в рублях. Источник — поля `usage` провайдера в SSE, а не длина текста. Между событиями провайдера счётчики могут не изменяться. Служебное мышление не публикуется; если провайдер включает его токены в output usage, они входят в выходной расход.

Стоимость — оценка по опубликованным тарифам DSLab на 22.10.2026. Это не баланс аккаунта и не подтверждённое списание. Тарифы находятся в `provider_gateway/main.py`. Кеш учитывается отдельно, включая разную стоимость записи на 5 минут и на час. Данные Codex в эти счётчики не входят. При переключении обратно на Codex история расхода DSLab сохраняется.

Статистика хранится в SQLite в приватном Docker-томе `provider_usage`. Обновление страницы, закрытие окна и пересоздание контейнера её не удаляют. `docker compose down -v` удаляет тома, включая статистику и существующую авторизацию Codex. Стандартные архивы проекта не включают отдельный том статистики.

Если поток оборвался до итогового usage, сохраняется известная часть и отметка неполного учёта. Нулевые неизвестные данные не означают отсутствие списания. В этой попытке дальнейшие запросы блокируются; после проверки расхода можно явно продолжить работу.

## Лимиты и выполнение

Бюджет токенов, максимум ответа и число запросов применяются **к одной попытке раунда**, включая обращения специалистов. Новый раунд получает новый бюджет. Это не общий денежный лимит проекта. Для первого прогона поставь небольшой лимит раундов.

Перед запросом шлюз проверяет консервативный запас по размеру контекста и максимуму ответа. Поэтому остановка возможна раньше указанного бюджета. При ошибке, разрыве потока или TIMEOUT работа переходит на паузу; платные запросы автоматически не повторяются. Ручное продолжение создаёт новую попытку с новым бюджетом и сохраняет исходники и историю.

История сообщений внутри попытки ограничена 64 KiB сериализованного UTF-8 JSON.
Старые завершённые обмены инструментами удаляются целиком, без разрыва пар
вызов/результат и без изменения подписанных блоков в сохранённых сообщениях.
Исходный запрос сохраняется; вместо удалённых обменов добавляется небольшой
журнал файлов, команд и ошибок с указанием, что это не доказательство PASS.
Файлы проекта и полные логи на диске сохраняются. Событие `context.compacted`
показывает сокращение истории. Инструкции и описания инструментов передаются
дополнительно к этому окну, поэтому 64 KiB — не общий размер API-запроса.
Сокращение не требует отдельного платного вызова и не повышает бюджет.
Повторяемые входные токены, включая чтение кэша, по-прежнему учитываются
в локальном лимите токенов; кэширование не делает их бесплатными для лимита.

Claude читает и изменяет файлы, выполняет ограниченные по времени команды и запрашивает отдельные обзоры у специалистов. Специалисты работают в отдельных диалогах с инструментами чтения; они не изменяют код и не выдают результат неисполненного теста. Неограниченного дерева подагентов и встроенного поиска Anthropic эта интеграция не добавляет. Входные изображения/документы сейчас отключены; ТЗ и исходники передаются текстом.

Сборку, Minecraft, игровые проверки и приёмку по ТЗ продолжает запускать независимый контроллер. Смена модели не превращает заявления агента в доказательства готовности.

## Изоляция

`DSLAB_API_KEY` получает только `provider-gateway`. Шлюз не имеет проектов, файлов хоста или Docker socket. Он отправляет запросы только на `https://api.dslab.tech`, через существующий фильтр внешней сети.

Контейнер `agent-dslab` не получает API-ключ, внутренний секрет управления, авторизацию Codex, базу заданий, артефакты или Docker socket. Он получает ограниченный доступ к одной попытке с фиксированной моделью, бюджетом и сроком действия. После завершения доступ отзывается. Агент использует те же разрешённые папки `projects` и `agent-tasks` внутри Lab; прямые файловые инструменты ограничены текущим workspace.

Связь со шлюзом идёт через Unix socket в Docker-томе; TCP-порт шлюза не публикуется. Контроллер остаётся без TCP-сети. Передаваемые модели фрагменты ТЗ, исходников и результатов инструментов обрабатываются DSLab и его провайдером.

Документация API и тарифов: [Sonnet](https://dslab.tech/ai/models/llm/claude-sonnet-5-5), [Opus](https://dslab.tech/ai/models/llm/claude-opus-5-5).
