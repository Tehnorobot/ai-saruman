# Бюджеты API

В настройках проекта → выбор моделей → «Лимиты API на раунд» можно задать:

- общий бюджет токенов: вход, выход и кеш;
- максимум токенов одного ответа, включая thinking;
- число запросов в раунде, включая коррекции и повторы.

Верхние границы приложения 1000 запросов, 100 млн токенов бюджета и 32768 токенов ответа сняты. Внутренние дополнительные границы шлюза 10000 запросов и 64000 токенов ответа также сняты. Новые значения сохраняются и передаются без обрезания.

Значения должны быть целыми. Сохраняется технический диапазон точных целых чисел браузера: до `2^53-1`. Это ограничение представления числа, а не квота провайдера. Минимумы: бюджет 1000, ответ 1024, запросы 1.

Заданные пользователем бюджеты по-прежнему проверяются. Изменение настроек не сбрасывает уже потраченные токены и запросы. Для продолжения после исчерпания бюджета укажите новый общий лимит, который больше уже использованного, сохраните настройки и нажмите «Продолжить».

Максимальный ответ должен поддерживаться выбранной моделью и провайдером. Приложение не подменяет модель и не уменьшает выбранный размер молча. Перед запросом шлюз также проверяет оставшийся бюджет с резервом на вход и ответ. Большой предел ответа требует достаточного оставшегося бюджета.

Эти настройки применяются к API-провайдерам. Они не меняют квоты подписки Codex/ChatGPT. Значения действующих проектов автоматически не повышаются.
