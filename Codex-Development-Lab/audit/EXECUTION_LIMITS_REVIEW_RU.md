# Контекст, диагностика и пределы выполнения — 25.10.2026

## Причина сбоя MiniMax

Проверена попытка `fd124aec0a1647-round12-b6bdff05ef9c4570882e84f4d997a45a`:
MiniMax-M3.1-Flash, reasoning low, TIMEOUT 600.5 секунды.
В журнале 128 завершённых ответов модели, 216 операций чтения/поиска,
104 сокращения истории. Один и тот же фрагмент теста получен 32 раза.
Исходный запрос занимает 41 154 байта из прежнего окна 65 536 байт.
К концу попытки удалены 127 обменов. Это подтверждает повторное чтение;
удаление контекста — вероятный усилитель цикла, но не доказанная единственная причина.

## Сохранённые границы

- Пользовательские бюджеты токенов, запросов и раундов, отзыв capability и пауза.
- 8 МиБ на API-запрос и явная проверка перед его отправкой. Размер в байтах не равен токенам модели.
- Предельное настраиваемое окно истории 4 МиБ: оно оставляет место для system/tools и JSON.
- Ограниченные порции чтения с пагинацией. Большой документ читается частями.
- Отдельные ограниченные обзоры дочерних агентов и пакет независимой проверки до четырёх сценариев.
- Защита путей, запрет symlink/hardlink для доказательств, проверка хешей и безопасный XML.
- Изоляция контейнеров, read-only planner, запрет Docker socket у агентов, лимиты CPU/RAM/PID.

Бюджет API по-прежнему делится между планировщиком и кодером 20/80;
это показано в UI. Резерв следующего запроса консервативен и может остановить
запрос до полного расходования номинального бюджета. Эти финансовые ограничения
не отменены. Ограниченный экспорт диагностики не является полной копией всех
артефактов: пропуски отмечаются, исходники доказательств сохраняются отдельно.

## Настройка без редактирования кода

В `.env.example` добавлены параметры, настоящий `.env` не менялся:

```dotenv
AGENT_TIMEOUT_SECONDS=3600
PLANNER_TIMEOUT_SECONDS=
API_CONTEXT_BYTES=524288
```

Пустой PLANNER_TIMEOUT_SECONDS означает наследование общего времени.
API_CONTEXT_BYTES применяется к DSLab, LiteLLM и MiniMax; диапазон
65 536–4 194 304 байта. Последний полный ответ инструмента может превысить
целевой размер окна, но не жёсткий предел API-запроса.
Старое имя DSLAB_CONTEXT_BYTES поддерживается при отсутствии нового.

## Границы проверки

Регрессии воспроизводятся локально без платных запросов: большой исходный запрос,
полные signed tool exchanges, повторные чтения, более 100 запросов, длинный JSON,
журнал >8 МиБ, таймаут >600 секунд, поздняя причина сбоя и FAIL за первыми
16 проверками/4 XML. Итоги Linux-тестов и установки фиксируются отдельно
в `execution-limits-validation.json` и `execution-limits-deployment.json`.

Полный набор в Linux-контейнере: 893 теста, OK, 29 пропусков; 25.359 секунды.
Контейнер был без сети и пользовательских подключений, с read-only filesystem
и удалёнными capabilities. `docker compose config --quiet` выполнен успешно.

Живой оплачиваемый прогон MiniMax не запускался. Исправления устраняют найденные
дефекты исполнителя, но не гарантируют отсутствие повторных действий у любой LLM.
