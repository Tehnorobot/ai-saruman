# Проверка обновления планировщика и полноты приёмки

Изменения установлены в dashboard, worker и исполнители агентов. Runner перезапущен
на паузе для фиксации нового образа сборки. Все задания сохранили состояние, раунд,
выбранные модели и поколение возобновления. Модели при установке не вызывались.

## Изменения

- Условия берутся из исходного текста ТЗ и получают стабильные идентификаторы.
- Привязка теста к требованию больше не доказывает полноту требования.
- Планировщик проверяет покрытие независимо от кодера. Контроллер проверяет состав
  условий, сценарии и цитаты из фактически прочитанных тестов.
- Одобрения хранятся вне доступного кодеру workspace и привязаны к версиям входных данных.
- Очередь учитывает пропущенные условия уже частично проверенного требования.
- Текущие факты сценариев имеют приоритет над старыми заметками; сохранённый план
  проверяется на актуальность перед новым запуском кодера.
- Обзор покрытия может проходить без кодера; пустая очередь сценариев не запускает
  общий игровой тест без выбора сценария.
- Панель показывает частичное покрытие, условия и отдельную историю сценариев.

## Проверки

- Итоговый Linux-образ: `unittest discover -s tests -q` — 656 тестов, OK,
  28 пропущены. Изолированный запуск: без сети, файловая система образа только
  для чтения, без полномочий и учётных данных.
- Edge: общий dashboard — PASS для пяти сочетаний размера и страницы, включая
  ширину 390; проверены навигация, настройки, отсутствие переполнения и сохранение
  видеоплеера при обновлении данных.
- Edge: условия покрытия — 11 проверок PASS; история приёмки — 17 проверок PASS.
- Независимый обзор новых ветвей workflow: четыре интеграционных теста PASS.
- Первый общий браузерный запуск внутри ограниченной среды завершился сбоем
  GPU-процесса Edge. Повторный разрешённый запуск с теми же проверками прошёл.

## Практические ограничения

Механическая проверка цитат не доказывает правильность смыслового вывода модели.
В одном фрагменте ТЗ могут оставаться несколько условий: обзор обязан учесть все.
Проверка качества планов с реальной моделью после обновления ещё не выполнялась:
задание оставлено на паузе, платные запросы не отправлялись.
При редком восстановлении после сбоя между обзором, сменившим текущую группу, и
сохранением завершения разработки прежняя цель может быть отклонена при повторной
валидации. Это безопасная остановка, а не ложный PASS.
