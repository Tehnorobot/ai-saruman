# Исправление ложного отказа цитаты и приоритета реализации

Дата: 2026-10-24. Текущий проект `20a4c385b26c4b`, задание `f86241b7d5b24e`.

## Что изменено

**Цитаты.** `common.coverage.read_evidence` сначала разбирает табуляционный
префикс `nl -ba`, затем другие форматы нумерации. Операторы Java `||` сохраняются.
Исходный excerpt проверяется точно по файлу и больше не обрабатывается как
нумерованный вывод. Пустая нормализованная цитата отвергается.
Сохранённый журнал раунда 9 воспроизведён: все семь ссылок теперь принимаются.

**Приоритет поведения.** Новый `common.functional_priority` после подтверждения
сборки и базового игрового запуска выбирает явное поведенческое условие текущей
группы в разделе «Цель». Для него контроллер требует реализацию точного REQ и
condition ID, `verification_kind=gameplay` и конкретный `verification_objective`.
Обзор покрытия и новая упаковка вместо этого действия отвергаются. Первый срез
не обязан реализовать все положения большого абзаца: он должен дать настоящее
игровое поведение и исполняемый сценарий. Приоритетные проверки выбираются по
точным условиям раньше других сценариев широкого требования.

Распознавание консервативное: неизвестный/неоднозначный текст не угадывается.
Схема, сборка и текущие игровые регрессии сохраняют приоритет ремонта.
Mapping без исполнения не освобождает функциональный этап. После фактической
попытки игрового сценария возможны обычный ремонт и обзор. Это правило маршрутизации,
не доказательство полного покрытия и не назначение PASS.

Для текущего задания проверка без модели выбрала:

```text
REQ-00005-800a4cc427
condition-318562864fe875f3
Реализовать автоматическую атаку и защиту через задачи и контроллеры UnionClef:
использовать его навигацию, инвентарь, инструменты и доступные боевые механизмы.
```

**Восстановление.** Завершённый транспорт отклонённого обзора больше не повторяется
при возобновлении. Старый журнал сохраняется, завершённый результат удаляется
из транспорта, затем запрашивается новый план. Незавершённый процесс не удаляется.
Новая директива входит в ревизию контекста; старый сохранённый план не получает
права обходить её. ТЗ и код аддона не переписываются.

## Установка

Обновление ставится только при отсутствии активных заданий. Состояния, раунды и
модели сохраняются. Контекст текущего проекта обновляется под штатной блокировкой
до следующего раунда с новой директивой. Модели и Minecraft не запускаются,
задание не возобновляется автоматически.

Артефакты: `audit/functional-goal-deployment.json`,
`audit/functional-goal-context.json`.

Реальное выполнение новой боевой задачи моделью ещё не проверено: его результат
должны подтвердить последующий игровой сценарий и независимая приёмка.
