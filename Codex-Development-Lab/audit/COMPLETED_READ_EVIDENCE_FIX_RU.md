# Проверка прочитанных доказательств

Ошибка обнаружена в обзоре покрытия раунда 21 задания f86241b7d5b24e.
Планировщик прочитал DistributionClientTest.java и процитировал вызов
DistributionOrigins.requireInstalledFile на строке 38. Последний поиск rg
в составной команде не нашёл совпадений и вернул код 1. Контроллер учитывал
вывод только команд с кодом 0, поэтому потерял успешно прочитанные строки.

common/coverage.py теперь учитывает stdout завершённой команды с любым
целочисленным кодом выхода как наблюдение. Это не меняет результат команды
или теста. Незавершённые команды и сообщения самой модели доказательством
не считаются. Цитата по-прежнему должна совпадать с реальным файлом.

Все 10 ссылок сохранённого обзора проверены повторно и приняты.
Добавлены три регрессионных теста. Полный набор: 741 тест, OK, 28 пропущены.

Примеры итогового JSON и coverage_reviews уже есть в worker/planner.py.
Ответ планировщика соблюдал формат. Pydantic в этом исправлении не добавлен:
проверка структуры JSON не заменяет проверку фактического чтения исходников.
При внедрении схемы необходимо сохранить динамические проверки известных
требований, строк исходников, наблюдений инструментов и независимых результатов.

Обновление не возобновляет задания и не вызывает модели. Результат установки
сохраняется отдельно в completed-read-deployment.json.
