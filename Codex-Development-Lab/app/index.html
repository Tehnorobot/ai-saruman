Загрузи ТЗ в формате Markdown. Skills подключаются автоматически.

Уровень применяется к выбранной модели на каждом раунде. Набор поддерживаемых уровней зависит от модели и доступа твоего аккаунта. Неподдерживаемая комбинация даст явную ошибку Codex без скрытой смены модели.

Модели по ролям можно изменить после создания проекта. Раунд не означает готовность мода.

Приёмка по ТЗ

«Тесты пройдены» означает успешное выполнение связанных исполняемых проверок. Это не доказывает полноту ТЗ и правильность всех игровых ситуаций. Итог требует проверки покрытия и доказательств.

Видео загружается только по нажатию. Для API и других ненаблюдаемых требований доказательством служат проверки и журналы; искусственное видео не требуется.
